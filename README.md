# NextBank 

**An AI-assisted digital banking simulator built with Java.**

## Project vision

NextBank AI is a learning-oriented portfolio project exploring how a secure Java application can help customers understand their simulated financial activity through transparent analytics and responsible AI assistance.

## Problem statement

Banking data can show customers their transactions without helping them understand spending patterns. This project explores a more understandable financial experience using deterministic analytics and AI-generated explanations.

## Core principles

- Java-first backend development.
- Clear separation of business logic and presentation.
- Financial calculations performed by deterministic application logic.
- AI used for explanations, not autonomous financial transactions.
- Security, privacy, testing, and maintainability considered throughout development.
- Incremental development using Git and GitHub.

## Technology roadmap

- Java 24 and Maven
- Spring Boot and Spring Security
- MySQL and Spring Data JPA
- React and TypeScript
- Spring AI with an external model API
- JUnit, Mockito, Docker, and GitHub Actions

Technologies will be introduced incrementally as the project develops.

## Scope and disclaimer

This is an educational banking simulator using synthetic data. It is not a real bank, does not hold customer funds, and is not intended for real financial transactions.

## Learning objectives

Practice Java fundamentals, object-oriented design, database integration, REST API development, secure application design, testing, version control, and responsible AI integration.
